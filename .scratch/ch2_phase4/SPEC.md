## Problem Statement

NeosisLM's Chapter 2 migration to Open Notebook Ground requires a final cutover phase (Phase 4). While the basic integration (Phases 1/2) and production hardening (Phase 3) have been completed, the application still uses inline branching in route handlers to select the active Ground engine. A formal, tested, and reliable cutover must be executed.

## Solution

Evaluate the new Open Notebook execution path against a rigorous offline integration testing matrix to establish production readiness. Safely make Open Notebook the default authoritative engine via a formal dependency-injected Factory Router, while keeping the legacy engine available explicitly for rollback purposes using existing configuration patterns.

## User Stories

1. As an operator, I want to evaluate the Open Notebook implementation's functional correctness offline using Pytest, so that I have a hard CI gate for production readiness without relying on live shadow testing.
2. As a backend developer, I want a cleanly abstracted `GroundEngineFactory` exposed via FastAPI dependency injection, so that route handlers are decoupled from engine selection logic and remain trivially mockable.
3. As a deployment engineer, I want `OPEN_NOTEBOOK_ENABLED` to default to `True`, so that the cutover occurs without introducing new configuration keys or complex fallback matrices.
4. As an incident responder, I want to toggle `OPEN_NOTEBOOK_ENABLED=False` to explicitly and safely rollback to the legacy engine, so that production outages can be rapidly mitigated.
5. As an SRE, I want Open Notebook requests to carry a propagated `X-Neosis-Run-ID` correlation header, so that I can trace execution logic between Neosis and Open Notebook via logs when OpenTelemetry traces are fragmented.
6. As a developer, I want the legacy `GroundModeOrchestrator` to be visibly deprecated via `@deprecated` and log warnings, so that future development naturally migrates away from it without breaking existing rollback capabilities.
7. As an operator, I want a non-blocking telemetry event to fire when the legacy engine is instantiated, so that I can monitor fallback usage and eventually plan its complete removal.

## Implementation Decisions

- **Evaluation**: The production-readiness gate will be an explicit Pytest Integration Matrix testing the Open Notebook dependency against core invariants (tenant isolation, provenance, backpressure).
- **Engine Routing Boundary**: A `get_ground_engine` FastAPI dependency will abstract the `OPEN_NOTEBOOK_ENABLED` branch out of the `ask_ground_mode` routes.
- **Configuration Defaults**: The core `OPEN_NOTEBOOK_ENABLED` feature flag will remain, but its default value will be flipped to `True`. `False` is retained solely as an explicit rollback mechanism. No `LEGACY_GROUND_ENABLED` flag will be introduced.
- **Legacy Deprecation**: `GroundModeOrchestrator` will use standard Python `@deprecated` decorators and emit `logger.warning` on instantiation. A non-blocking telemetry event `legacy_ground_engine_instantiated` will be recorded upon initialization to provide migration observability.
- **Telemetry Propagation**: The existing OpenTelemetry trace propagation will be supplemented by explicitly injecting `X-Neosis-Run-ID`, `X-Neosis-Task-ID`, and `X-Neosis-Request-ID` HTTP headers into all downstream Open Notebook calls. These must be derived from the active execution context, not randomly generated by the client.

## Testing Decisions

- **CI Gating**: The primary validation is an offline `tests/integration/test_phase4_evaluation.py` suite. This asserts all functional requirements without a live "shadow" production deployment.
- **Routing Assertion**: Dedicated tests will verify that when `OPEN_NOTEBOOK_ENABLED=True`, the legacy engine is not instantiated (verified by the absence of the `legacy_ground_engine_instantiated` metric/warning).

## Out of Scope

- Building a live "shadow mode" production comparison script.
- Removing or deleting the legacy `GroundModeOrchestrator` entirely.
- Modifying or migrating Research Mode (strictly out of scope for the entire Ground migration).
